# Fridge Rescue

A tiny AI-powered meal generator built with Next.js and OpenAI.

Users enter:

- ingredients
- mood

The app generates:

- a meal idea
- cooking steps
- why the flavors work
- a wine pairing

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- OpenAI API
